## 1. 画像与使用场景

- **用户画像**：第一次用这类"音源插件型"音乐软件，眼神一般、手指不如年轻人灵活，怕按错、按错希望能退回来。
- **最在意**：打开就能听到歌、入口一眼能找到、看不懂的词有大白话解释、误触能撤销或有提醒、不要突然没声音还不知道为啥。
- **典型场景**：
  1. 装完第一次打开 → 走完引导 → 进首页想"随便放首歌听听"。
  2. 在底部点"搜索"，想搜一首熟悉的歌；结果可能提示"还没有安装插件"。
  3. 歌放起来后，想看清歌词、调大歌词字、切"列表循环/单曲循环"。
  4. 偶尔进"设置→音效"，被"交叉馈送/卷积混响/ViPER-DDC/电子管"吓到，不知道点了会怎样。

## 3. 确定 bug 清单

> 格式：严重度 | 文件:行号 | 触发条件 | 后果

- **B1（P1）｜新用户空音源引导指向不存在的"侧边栏"**
  - 文件：`src/components/base/noPlugin.tsx:21-27`（文案取 `noPlugin.description` = "先去「侧边栏-插件管理」里安装插件吧~"，zh-cn.json:359）。
  - 触发：未成功安装音源时进入搜索 tab（searchPage/index.tsx:47-49 渲染 NoPlugin）。
  - 后果：本 fork 首页是底部 4 Tab（首页/搜索/音乐库/我的），**没有侧边栏**；音源实际入口在「我的 → 音源管理」（mineTab.tsx:130-134 → PLUGIN_SOURCES）。新用户被引导去一个不存在的入口，形成死路，容易以为软件坏了。

- **B2（P1）｜清空搜索历史无二次确认**
  - 文件：`src/pages/searchPage/components/historyPanel.tsx:95-103`。
  - 触发：误触右上角"清空"按钮。
  - 后果：直接 `await removeAllHistory()`，无确认弹窗、无 toast、不可撤销。与"删除歌单有确认"（sheets.tsx:57）不一致。

- **B3（P1）｜清空最近播放无二次确认**
  - 文件：`src/pages/history/index.tsx:36-39`。
  - 触发：误触顶栏垃圾桶图标。
  - 后果：直接 `musicHistory.clearMusic()`，全部播放记录立即清空，无确认、无撤销。

- **B4（P1）｜"重置全部 JamesDSP"无二次确认**
  - 文件：`src/pages/setting/settingTypes/soundEffectSetting.tsx:724-737`。
  - 触发：误触"重置"行。
  - 后果：立即把 postGain/低音/立体声/混响/电子管/交叉馈送/DDC 全部写回关闭并 `resetJamesDsp()`，无确认弹窗、无 toast。用户辛苦调好的音效一键归零。

- **B5（P2/P1）｜新手引导承诺的"权限管理"无法补开通知权限**
  - 文件：`Onboarding.tsx:91-144`（申请 POST_NOTIFICATIONS）+ `Onboarding.tsx:506-511`（提示"之后可在「我的 → 设置 → 权限管理」补开"）；对照 `src/components/dialogs/components/permissionSettingDialog.tsx:115-146`。
  - 触发：用户在引导第2屏拒绝了"通知"权限。
  - 后果：权限管理浮窗只有"悬浮窗权限""文件读写权限"两行，**没有通知开关**。用户此后没有任何应用内入口重新开启通知权限，与引导承诺不符。

- **B6（P2）｜"每日推荐"异步失败静默、点击无反应**
  - 文件：`src/pages/home/components/homeBody/operations.tsx:43-91`。
  - 触发：点"每日推荐"时网络异常或 `getFirstAvailablePluginRecommend()` 走 reject。
  - 后果：整条 `.then(...)` 链**没有 `.catch`**，失败时既不跳转也不弹提示，界面毫无反应，老人不知道是网不好还是没点中。

- **B7（P2）｜音效页整个"进阶音效/JamesDSP"区块硬编码中文、未走 i18n**
  - 文件：`soundEffectSetting.tsx`：443"进阶音效"、449"输出增益"、468"动态低音 (DBB)"、499"立体声增强"、530"混响"、553"算法混响"、560"卷积混响"、612"电子管模拟"、622"驱动增益"、643"交叉馈送 (Crossfeed)"、673"ViPER-DDC 耳机补偿"、716"导入"、735"重置全部 JamesDSP"、761"音效引擎：JamesDSP"/767"已就绪"/768"播放后生效"。
  - 触发：用户把语言切成繁体中文。
  - 后果：同一文件 EQ 区块已用 `t(...)`，进阶区块却全部硬编码简体，切繁体后此处仍是简体；与 i18n 体系不一致。同类硬编码：`basicSetting.tsx:365`"开机自启动"、`historyPanel.tsx:159`"热门搜索"/168"热门搜索加载失败…"、`history/index.tsx:48`"最近播放"/124"暂无播放记录"、`mineTab.tsx` 全部入口文案。

- **B8（P2）｜有用的音效说明文案已在 i18n 中但从未渲染**
  - 文件：zh-cn.json:465 `soundEffect.hint`="音效实时作用于当前播放，需播放过歌曲后生效；换歌不重置设置。"；以及 `soundEffect.bass`/`virtualizer`/`diagBassOk`/`diagBassNo`/`diagVzOk`/`diagVzNo`/`sectionFx`/`preset`。
  - 触发：源码检索确认这些 key 只在 `types/core/i18n/index.d.ts` 出现，**没有任何 .tsx/.ts 引用**。
  - 后果：正好能解答新用户"我调了音效怎么没声音/没变化"的那句大白话说明（hint），并没有显示在音效页；属于有资源却没用上。

## 4. 可优化建议

### P1（功能性，明显影响新手中老年使用）

- **P1-1 播放模式切换不可理解、无反馈**：`musicDetail/components/bottom/playControl.tsx:43-54` 循环/随机按钮只渲染 `repeatModeConst[repeatMode].icon`；`src/constants/repeatModeConst.ts:11-24` 里已有"列表循环/单曲循环/随机播放"中文文案却没用；`trackPlayer/index.ts:860-886 setRepeatMode` 切换时**不弹 toast**。老人点完图标变了，不知道现在是哪种模式、会不会重复。建议：切换后 toast 出"已切换为：单曲循环"，并在图标旁常驻一个小字模式名。

- **P1-2 播放页字号整体偏小、无大字模式**：手机端歌名 19sp（`musicDetail/index.tsx:164`）、歌手 13sp（:181）、进度时间 caption≈11sp（`bottom/seekBar.tsx:77`）；音效页滑块宽 `rpx(200)`（soundEffectSetting.tsx:450 等）拇指偏小。建议：设置里加"大字/长辈模式"全局放大；播放页歌名默认再大一档。

- **P1-3 封面↔歌词切换是隐藏手势、顶栏图标语义隐晦**：`musicDetail/components/content/index.tsx:17-26` 点封面才切歌词，无任何"点封面看歌词"提示；`musicDetail/components/navBar.tsx:30-38` 用"T恤衣服"图标代表"沉浸歌词外观设置"，新用户根本联想不到。建议：封面角落加小字"点这里看歌词"；T恤图标换成文字"歌词样式"或加 accessibilityLabel。

- **P1-4 音效专业术语无通俗说明**：soundEffectSetting.tsx 中"输出增益/动态低音 DBB/立体声增强/电子管模拟/交叉馈送 (Crossfeed)/ViPER-DDC 耳机补偿/算法 vs 卷积混响"均只有标题、无 description 副标题；dB/% 单位老人不懂。建议：每项加一行大白话副标题（如"交叉馈送：戴耳机时让左右声音更像在一个房间里"），并把 B8 那条 hint 渲染出来。

### P2（体验/文案/细节）

- **P2-1 空态"我的歌单"文案无下一步**：`homeBody/sheets.tsx:158-163` 空态显示 `common.emptyList`="什么都没有呀~"（zh-cn.json:350），而旁边就有"+新建/导入"按钮却不提示。建议改成"还没有歌单，点右上角 + 新建一个"。
- **P2-2 无障碍标签大面积缺失**：手机底部 4 Tab（tabBar.tsx:79-106）、播放页各图标按钮（playControl、lyricOperations、musicDetail/navBar）几乎都没有 `accessibilityLabel`（仅平板齿轮 tabBar.tsx:192 有）。读屏用户无法操作。
- **P2-3 首页推荐区静默隐藏**：`recommendSection.tsx:253-255` 无插件时整段 `return null`，建议至少给一行"在线推荐需要先在『我的→音源管理』装音源"。
- **P2-4 新手引导第3屏开关偏多**：Onboarding.tsx:543-667 一屏 4 个开关（自动更新音源/移动网络播放/扫描本地/进入自动播放），"音源""订阅"等词无解释。建议默认全选并折叠为"高级选项"。
- **P2-5 误触防护补齐**：B2/B3/B4 三处清空/重置补二次确认后，删除类操作即可统一有确认。
