# 启动图 / 启动画面调研汇总

> 合并自 6 份调研文档（原 `docs/research/01–06`），统一调研日期 2026-10-14。
> 覆盖三层：①开源音乐 App 启动图真实实现（网页快照 + 本地 clone 源码核验）；②Android 系统 SplashScreen API 官方规格与限制；③RN/Flutter 三大启动图库源码机制。
> **可信度约定**：凡"本地核验"结论以 `git clone` 到的源码为准（04/05/06 已推翻 01 的多处旧快照结论）；纯引用代码一律附来源。

---

## 〇、核心结论速览

1. **开源音乐 App 没有一个真正做"全屏整图启动"**。主流是两条路：
   - 旧式（API<31）：`windowBackground` 用 `layer-list`（纯色底 + 居中 Logo 位图，`gravity=center` 不拉伸）。
   - 新式（API31+）：交给 Android 12 系统 Splash（纯色底 + 居中图标/动画矢量），或接入 `androidx.core:core-splashscreen`。
2. **系统 Splash 层不支持全屏背景图/渐变**：`windowSplashScreenBackground` 只能是单一不透明颜色；中间图标被圆形蒙版裁切（最大 288dp、内圆 192dp）；底部 branding 图仅 200×80dp 且官方明确"不推荐"。
3. **`windowSplashScreenShortTimeout` 在官方文档中不存在**，是讹传（详见 §2.4），写入会报 attribute not found。
4. **RN/Flutter 库定位**：
   - `expo-splash-screen`（现代）= AndroidX `core-splashscreen` 的封装（系统 Splash + 主题切换）。
   - `react-native-splash-screen`（crazycodeboy，老）= 自建 Dialog 遮罩 hack，不具备系统 Splash 能力，API31+ 有双启动屏风险。
   - `flutter_native_splash` = 切图（5 档 dpi）+ 拼 `launch_background.xml` 模板 + 写 `values*` 主题属性，不依赖兼容库。
5. **对极悦界**：现有"原生 `windowBackground` layer-list + `values-v31` 系统 splash（纯色+圆底+白音符）+ `expo-splash-screen`"已是 Android 12+ 下系统层能做到的极限；"看不出系统纯色"靠**让系统 Splash 背景色与 App 首帧窗口底色用同一 color resource**，而不是往系统槽位塞整图。

## 一、开源音乐 App 启动图实现（本地核验为准）

### 1.1 总览表

| App | 旧式(<31) | 新式(≥31) | 评级 |
|---|---|---|---|
| Retro Music | layer-list（`?attr/colorPrimary` 满屏 + 居中 512×512 PNG logo） | `values-v31`：`parent=Theme.SplashScreen` + `avd_splash` 动画矢量图标（1000ms） | 「纯色底 + 居中 Logo」双轨 |
| Metro（Retro fork） | 同 Retro（逐字一致） | 同 Retro（core-splashscreen 1.0.0 + avd_splash） | 「纯色底 + 居中 Logo」双轨 |
| Auxio | 无自制（继承 Material3 默认） | `values-v31`：`ic_splash_anim` 432dp 自绘 A 形描边动画图标 | 「系统 Splash + 自制动画图标」，背景 100% 交系统 |
| VLC | 透明 `StartActivity` 直接跳 MainActivity，无品牌图 | 系统 Splash 自动（launcher icon） | 反启动图 |
| Phonograph | 无任何自制：manifest 主题即浅色正式主题，冷启动画系统默认白底 | 无 values-v31 / 无 windowSplashScreen*（targetSdk 29） | 纯系统默认 |
| Signal（佐证） | — | `values-v31`：`windowSplashScreenBackground=正式主题 windowBackground`（同一 color）+ `ic_splash` vector | 官方最小可用 Splash |
| Nextcloud（佐证） | — | core-splashscreen：`windowSplashScreenBackground` + 复用 `ic_launcher_foreground` + `postSplashScreenTheme` | 官方推荐三段式 |
| Aegis（佐证） | — | 仅透明状态栏，无 windowBackground / windowSplashScreen* | 纯系统默认 |

### 1.2 Retro Music / Metro：旧式 layer-list + 新式系统 Splash 双轨

**关键文件与代码**（Retro commit `a7d4d05b`，2026-09-29，targetSdk 36；Metro commit `32e0a24`，2023-04，targetSdk 33，父依赖 `androidx.core:core-splashscreen:1.0.x`）：

- Manifest：启动 Activity 单独挂 `android:theme="@style/Theme.RetroMusic.SplashScreen"`。
- `values/styles.xml`（API<31）：
  ```xml
  <style name="Theme.RetroMusic.SplashScreen" parent="Theme.AppCompat.DayNight.NoActionBar">
      <item name="android:windowBackground">@drawable/splash</item>
      <item name="android:statusBarColor">@android:color/transparent</item>
  </style>
  ```
- `drawable/splash.xml`（layer-list，两层）：
  ```xml
  <layer-list xmlns:android="http://schemas.android.com/apk/res/android">
      <item android:drawable="?attr/colorPrimary" />            <!-- 第1层：主题色满屏 -->
      <item>
          <bitmap android:gravity="center" android:src="@drawable/ic_splash" />  <!-- 第2层：居中不拉伸 -->
      </item>
  </layer-list>
  ```
- `ic_splash.png`：**512×512 PNG，只出 `drawable-xxxhdpi/` 一档**，非 vector，无 nodpi。
- `values-v31/styles.xml`（API31+）：
  ```xml
  <style name="Theme.RetroMusic.SplashScreen" parent="Theme.SplashScreen">
      <item name="android:windowSplashScreenAnimatedIcon">@drawable/avd_splash</item>
      <item name="android:windowSplashScreenAnimationDuration">1000</item>
  </style>
  ```
  - `windowSplashScreenBackground` / `IconBackgroundColor` / `BrandingImage` / `postSplashScreenTheme` **均未设置**；`values-night-v31` 也未覆盖启动主题；全仓 grep `installSplashScreen` = 0 命中。
- `avd_splash.xml`：`<animated-vector>` 411dp，三角播放 logo 描边/填色动画（translateX 入场 + path morph），由主题时长 1000ms 控制。
- 运行时切主题：`AbsThemeActivity.onCreate()` 在 `super.onCreate()` **之前** `setTheme(getThemeResValue())` 切到正式主题（`windowBackground=?colorSurface`）。

**无缝机制**：旧设备第一帧就是 `windowBackground=splash.xml`（品牌色满屏+logo），不存在系统白底中间帧；新设备系统 Splash 用品牌动画矢量图标，背景走 Material3 `colorBackground` 系与首帧 `colorSurface` 同色系，色差极小。**未**显式对齐 splash 背景与首帧底色（赌默认色接近）。

### 1.3 Auxio：系统 Splash + 自绘动画图标

- commit `c05cebc5`，targetSdk 37（系统 Splash 完全生效），minSdk 24。
- `values-v31/styles_core.xml` 只设两项：`windowSplashScreenAnimatedIcon=@drawable/ic_splash_anim`、`windowSplashScreenAnimationDuration=1000`；无 background / IconBackgroundColor / BrandingImage / postSplashScreenTheme / windowBackground 定制。
- `ic_splash_anim.xml`：432dp animated-vector，4 条笔画描出"A"logo（strokeWidth 0→2，850ms + 150ms offset），`bg` group 全透明占位。
- 无缝靠 Material3 DynamicColors 隐式统一（`?attr/colorBackground` 与 `colorSurface` 同色板派生），**非显式工程**。

### 1.4 VLC：透明跳转（反启动图）

启动入口是透明的 `StartActivity`（`Theme.VLC.Transparent.NoUI`，`windowBackground=@android:color/transparent`）直接跳 `MainActivity`；正式主题 `windowBackground` 只是纯白/深色。无任何自制启动图 drawable。

### 1.5 Phonograph：纯系统默认（最"裸"）

- commit `d156872`（2020 归档），targetSdk 29，无 values-v31、无任何 windowSplashScreen*、无 core-splashscreen。
- manifest 主题即 `Theme.Phonograph.Light`，无独立 Splash 主题；全 res 唯一 windowBackground 是纯黑主题 `@android:color/black`。
- `onCreate` 在 `super.onCreate()` 前 `setTheme(用户主题)`。冷启动画系统默认白底；纯黑主题用户会白→黑跳变。

### 1.6 佐证 App（Signal / Nextcloud / Aegis）

- **Signal**（`values-v31/themes.xml`）：`windowSplashScreenBackground = @color/signal_colorBackground`，与正式主题 `windowBackground` 用**同一个 color resource**——"无缝衔接"最干净做法；`windowSplashScreenAnimatedIcon=@drawable/ic_splash`（vector，非 PNG）。
- **Nextcloud**（`values/styles.xml` + `values-v31`）：用 core-splashscreen（`parent=Theme.SplashScreen`），三段式：`windowSplashScreenBackground=@color/primary` + 复用 `@drawable/ic_launcher_foreground` + `postSplashScreenTheme=Theme.ownCloud.Launcher`（其 `windowBackground` 也是 `@color/primary`，与系统 splash 底色完全一致）。
- **Aegis**：仅 `Theme.Aegis.Launch` 设透明状态栏，无 windowBackground / windowSplashScreen* 定制。

### 1.7 关键机制：为何"看不出系统纯色"

1. **旧设备**：第一帧即 `windowBackground=layer-list(品牌色满屏 + 居中 logo)`，系统白/灰底根本没机会出现；`statusBarColor=transparent` 无突兀色条。
2. **新设备**：要么 `windowSplashScreenBackground` 与首帧 `windowBackground` 同 color resource（Signal/Nextcloud），要么赌 Material3 同色系（Retro/Auxio）；图标用品牌动画矢量而非系统 launcher 图标。
3. **品牌图放 `windowBackground` 而非 `windowSplashScreenBackground`**：后者在 Android 12+ 只能是纯色。想要"图+字+渐变"组合只能画进 windowBackground 的 layer-list / drawable；再配 `postSplashScreenTheme` 切到含整图的主题。

## 二、系统 SplashScreen API 官方规格与限制

官方主文档：https://developer.android.com/develop/ui/views/launch/splash-screen （镜像 developer.android.google.cn）

### 2.1 槽位速查表

| 属性 | 官方规格 | 关键限制 |
|---|---|---|
| `windowSplashScreenBackground` | 单一不透明颜色 | **不支持渐变/图片/透明**："single opaque color" |
| `windowSplashScreenAnimatedIcon` | 中间图标，vector，可 AVD 动画；默认=launcher icon | 圆形蒙版裁切：有底色 240dp 内圆 160dp；无底色 288dp 内圆 192dp；前景 1/3 被 mask |
| `windowSplashScreenAnimationDuration` | 图标动画时长 ms | 不控制 splash 停留时长；Android 13+ 自动从 AVD 推断 |
| `windowSplashScreenIconBackgroundColor` | 图标后圆形底色 | 仅在对比度不足时用；设了图标按 240dp 档裁切 |
| `windowSplashScreenBrandingImage` | 屏幕底部品牌图 | **200×80 dp**；官方设计指南**不推荐** |
| `windowSplashScreenBehavior` | Android 13+ 是否强制显示图标 | 默认 0 跟随系统 |
| `postSplashScreenTheme` | **非平台属性，是 core-splashscreen 库属性** | 见 §2.5 |

### 2.2 Background 只能纯色（官方原文）

> "The window background consists of a **single opaque color**. If the window background is set and is a plain color, it is used by default if the attribute isn't set."
> "Set a **single window background color with no transparency**."

推论：`windowSplashScreenBackground` 不能塞 layer-list / bitmap / 渐变 / 图片；官方没有"整页启动图"槽位。

### 2.3 BrandingImage / IconBackgroundColor

- **BrandingImage**：官方尺寸 200×80dp，位置屏幕底部居中，官方明确 "design guidelines recommend against using a branding image"。调研 8 个 App 无一使用；flutter_native_splash 是少数落地者（要求源图 800×320px）。坑：图不透明会被裁成矩形贴纸；深/浅色要两套；API<31 不生效。
- **IconBackgroundColor**：在圆形图标后垫一块**圆形纯色底**；设了则图标按"有底色"档裁切。

### 2.4 `windowSplashScreenShortTimeout` 考证（重点纠偏）

**官方文档中不存在该属性**。官方可配置属性清单只有：Background / AnimatedIcon / AnimationDuration / IconBackgroundColor / BrandingImage / Behavior + 兼容库 postSplashScreenTheme。所谓"ShortTimeout"是对"系统自动超时兜底"的讹传（官方只说 "the splash screen times out automatically"，未公开毫秒数，也未开放配置）。**不要写入 styles.xml，AAPT 会报 attribute not found。**

### 2.5 两条技术路线

**路线 A：平台 API 直连（flutter_native_splash / 多数开源 App）**
- 不引入 core-splashscreen，直接在启动主题上写 `windowSplashScreen*`；API<31 与 ≥31 用资源限定目录分流（`values/` vs `values-v31/`）。
- 不需要 `postSplashScreenTheme`——启动主题本身就是"进程启动主题"，首帧后框架切到正式主题。

**路线 B：core-splashscreen 兼容库（官方推荐 / Nextcloud / expo）**
- 建 `parent="Theme.SplashScreen"` 专用主题，Manifest 启动 Activity 指向它，`onCreate` 在 `super.onCreate()` 前调 `installSplashScreen()`。
- `postSplashScreenTheme` 指向 splash 结束后要切换的真实主题，避免启动主题泄漏到业务页。
- 在 API23+ 全版本复刻 Android 12 splash 外观。

## 三、RN/Flutter 启动图库源码机制

### 3.1 expo-splash-screen（现代方案，本项目采用）

- **底层依赖**：委托 `androidx.core:core-splashscreen` 的 `SplashScreen.installSplashScreen()`。
- **注入机制**：config plugin 生成独立启动主题 `Theme.App.SplashScreen`（`parent=Theme.SplashScreen`），塞 `windowSplashScreenBackground` / `windowSplashScreenAnimatedIcon` / `postSplashScreenTheme` / `android:windowSplashScreenBehavior`；MainActivity 注释掉 `setTheme(AppTheme)` 并在 `super.onCreate(null)` 前插入 `SplashScreenManager.registerOnActivity(this)`。**插件自己不写 windowBackground**。
- **隐藏机制**：`ReactMarker CONTENT_APPEARED` 自动隐藏 + OnPreDraw 拦截 contentView 绘制（API<33 时 setKeepOnScreenCondition 不生效的兜底）+ JS 手动 `hideAsync()`；退出动画 400ms alpha 淡出。**无超时兜底**——调了 `preventAutoHideAsync()` 但 bundle 失败会永久挂启动屏，需业务侧加 3~5s 兜底。
- **图标多屏**：按 288dp 透明画布 + mdpi~xxxhdpi 五档密度自动合成（logo 默认 100dp 宽，`bitmap gravity=center` 居中）；深色模式有 `drawable-night-*/` 全档位；resizeMode 三档 contain/cover/native。
- **注意**：`windowSplashScreenIconBackgroundColor` 默认不设（需要圆底要自己补）；未误加 `windowIsTranslucent`（那是 crazycodeboy 才需要）。

### 3.2 react-native-splash-screen（crazycodeboy，老方案，勿用）

- 自建 `Dialog` 盖在 Activity 上（`new Dialog(activity, themeResId)` + `launch_screen.xml` + `windowIsTranslucent=true` 透明窗口防闪白）。
- **完全不含系统 Splash 能力**，不碰 windowBackground；API31+ 会先系统 splash 再 Dialog，两段闪烁。
- 无内置尺寸计算、无 9-patch、无自动合成；深色模式靠用户自己 `drawable-night/`。
- 隐藏完全由 JS `hide()` 决定，无超时兜底。

### 3.3 flutter_native_splash

- 不"画"启动图，做三件事：①PNG 按 5 个 dpi 桶切图落 `drawable-*`；②拼 `launch_background.xml`（layer-list，底层 `background.png` `gravity=fill` 拉伸铺满——**API<31 可做全屏背景图**）；③往 `values*/values-v31*/values-night*` 的 `LaunchTheme` 塞 `windowSplashScreen*` 属性。
- **不生成 postSplashScreenTheme、不依赖 Theme.SplashScreen / installSplashScreen()**；直接改 Flutter 现成 `LaunchTheme`。
- `background_image`（整页背景图）：**API<31 生效（fill 铺满）；API31+ 完全不生效**（README 明确不支持）。
- API31+ 图标用 `windowSplashScreenAnimatedIcon`（README 规格：有底色 960×960px / 无底色 1152×1152px），branding 要求 800×320px。
- minSdk<31 才额外写 `values-v31/`。

## 四、对极悦界的可借鉴清单与坑

极悦界现状：`windowBackground` 用 layer-list（纯色底 + 居中圆角渐变容器 + 白音符），Android 12+ 系统 splash 用纯色 + 圆形品牌底 + 白音符 + `expo-splash-screen`（preventAutoHideAsync / hideAsync）。

### 4.1 可直接借鉴

1. **保持 layer-list 思路，把第 1 层纯色抽成独立 color resource**（如 `@color/splash_background`），并在 `values-v31` 让 `windowSplashScreenBackground` 引用同一资源（Signal / Nextcloud 做法，零跳变）。
2. **不要追求整图全屏 PNG**：调研无一 App 这么做（系统 splash 强制图标进 240dp 圆；旧版整图又遇 16:9/20:9/平板拉伸）。"纯色底 + 居中容器 + 音符"即开源标准答案，与现状一致。
3. **`windowSplashScreenAnimatedIcon` 用 vector**（Signal 用 `ic_splash`，Nextcloud 复用 `ic_launcher_foreground`），不要 576×576 PNG。
4. **`windowSplashScreenBrandingImage` 可考虑删**：官方不推荐、开源无人用、MusicFree 上游模板自带只是 expo 默认值。
5. **若想让 Android 12+ 无缝更早**：可学 Nextcloud 用 `postSplashScreenTheme` 切到自带 layer-list 的主题，比 JS 侧 hide 早一帧，少露白。
6. **`android:statusBarColor=@android:color/transparent`**（Retro）：启动期状态栏透明，不露突兀色条。
7. **图标出图按 288dp 画布**（expo 的 `canvasSize=288*multiplier`），避免被系统 mask 裁切。
8. **OnPreDraw 拦截思路**：若 API<33 上"系统 splash 一退就闪白/内容提前露出"，照 expo 在 `android.R.id.content` 挂 OnPreDraw return false 兜底。

### 4.2 需要警惕的坑

1. **`windowSplashScreenShortTimeout` 不存在**——别写，AAPT 报错（官方真无此属性）。
2. **expo 无超时兜底**：`preventAutoHideAsync()` 后 bundle 失败会永久挂启动屏，**业务侧务必加 3~5s 超时兜底 hideAsync()**（这是两个库都没做、必须自己补的）。
3. **不要混用 crazycodeboy 风格 Dialog 遮罩**：API31+ 双启动屏。
4. **windowBackground 与系统 splash 属性分工**：API<31 靠 windowBackground(layer-list)，API31+ 靠 windowSplashScreenBackground+AnimatedIcon；**两套背景色值必须一致**，否则版本切换瞬间变色。
5. **深色模式**：expo 用 `values-night/` + `drawable-night-*/` 全档位；极悦界若支持深色，windowBackground 也要一套 night 变体，否则深色下启动背景不跟随。
6. **`windowIsTranslucent` 不要乱加**：那是 Dialog hack 才需要的，系统 splash 下加了反而透明不可控。

### 4.3 方案完备性核对清单

- [ ] MainActivity 主题在 API31+ 含 `windowSplashScreenBackground`、`windowSplashScreenAnimatedIcon`、`postSplashScreenTheme`。
- [ ] API<31 含 `windowBackground`（layer-list：纯色 + 居中 bitmap）。
- [ ] 两套背景色一致；深色模式有 night 变体。
- [ ] 图标按 288dp 画布、五档密度（或 vector）。
- [ ] JS 侧 `preventAutoHideAsync()` + **超时兜底** + `hideAsync()`。
- [ ] 退出有淡出动画，不硬切。
- [ ] 未混用 Dialog 遮罩；未误加 `windowIsTranslucent`。
