## 五、重要说明与风险提示

1. **沙箱超时 ≠ 插件失效**：QQ音乐 / 聚合 / Apple Music / 好听轻音乐（hebijunge 版）等重型混淆插件在沙箱内加载超时被排除，但插件文件 HTTP 200。极悦界 App 的实际加载环境更宽松，可尝试「列表底部手动安装通道」实测；其中「好听轻音乐」kevinr 版已验证可搜并入选（排名 18），无功能损失。
