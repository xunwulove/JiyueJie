## 0. 结论先行（5 条）

1. **Android 12+（API 31+）系统 splash 官方契约 = 纯色不透明背景 + 居中圆形蒙版图标 +（底部 200×80dp 品牌条，官方不推荐）**。"全屏品牌图 / 渐变背景"系统层做不到，只能靠 `windowBackground`（layer-list / 整图）或首帧自绘页。
2. **开源音乐 App 没有一个做"全屏整图启动页"**。主流"无白屏"做法 = `windowBackground` 用 layer-list（纯色底 + 居中 logo），或纯色；Signal / Nextcloud 用"系统 splash 背景与 windowBackground **同一 color 资源**"实现无缝衔接。
3. **`windowSplashScreenShortTimeout` 不存在**（官方文档可配属性清单里没有它，AAPT 会报 attribute not found）——纠偏，勿写入 styles.xml。
4. **`windowSplashScreenBrandingImage` 开源社区几乎无人使用**（调研 7 个 App 零使用；MusicFree 上游模板带它只是 expo 默认值），Google 官方设计指南明确不推荐。
5. **RN 生态**：expo-splash-screen 现代分支 = `androidx.core:core-splashscreen` 的封装（正确路线，本项目同路线）；crazycodeboy/react-native-splash-screen = Dialog 遮罩 hack，API 31+ 会"系统 splash + Dialog"双段闪烁，**勿用**。

## 1. 已核验基线：上游 MusicFree 原版 & 国产软件实测

### 1.1 MusicFree 原版（本项目下游，本机已核验，未重复）

RN 官方模板启动图，**连自制启动图都没做**：

- `windowSplashScreenBackground` = 纯色 `#27282C`
- `windowSplashScreenAnimatedIcon` = `drawable/splashscreen_image.png`（576×576）
- `windowSplashScreenBrandingImage` = `drawable/spashscreen_branding_image.png`（400×160）
- 无 `windowBackground` 定制、无 RN 自制背景页

### 1.2 国产软件反编译实测（aapt2 资源层，见《启动页白屏问题与实现路径.md》§3）

- **网易云音乐 6.2.81**：Launcher = 独立 `LoadingActivity`；启动画面载体 = 主题 `windowBackground` = layer-list（近白底 `#F9F9F9` + 红色氛围渐变 + 居中品牌整图）；**系统 splash 属性零配置**（资源表 windowSplashScreen* 零命中）。
- **QQ音乐车机版 3.16.0.2**：Launcher = 独立 `AppStarterActivity`；载体 = 主题 `windowBackground` = layer-list（纯白底 + 居中 `splash_logo` 1399×693 + 底部品牌条 796×157）；**系统 splash 属性零配置**。

**核心结论**：所谓"国产软件一点开就是全屏品牌图、无白屏"，源码本质 = **启动 Activity 主题的 `windowBackground` 用 layer-list（纯色底 + 品牌整图 + 文字）**，窗口一创建 windowBackground 先于一切布局立即全屏绘制；系统 splash 保持默认纯色一闪，几乎不可感知。不是靠系统 splash 属性（大厂甚至完全不配置它）。

## 2. 五问逐答（证据详见各分报告）

### Q1 开源 App 如何用 windowBackground 做全屏自制启动图？如何与系统 splash 无缝衔接？

| App | windowBackground | 系统 splash（v31） | 证据文件 |
|---|---|---|---|
| Retro Music / Metro | `layer-list`：层1 `?attr/colorPrimary` 纯色 + 层2 `<bitmap android:gravity="center" src="@drawable/ic_splash">`（居中不拉伸） | 无（targetSdk 29，跑不到 API31） | `app/src/main/res/values/styles.xml` + `drawable/splash.xml`，RetroMusicPlayer/RetroMusicPlayer、MuntashirAkon/Metro |
| VLC | `@android:color/transparent`（透明 StartActivity 跳 Main） | 系统默认（launcher icon） | `application/vlc-android/res/values/styles.xml` |
| Auxio / Aegis | 不设置（Material3 默认） | 系统默认 | `values/styles_core.xml`、`values/themes.xml` |
| Signal | `@color/signal_colorBackground`（纯色） | `windowSplashScreenBackground=@color/signal_colorBackground`（**同一 color resource**）+ AnimatedIcon=vector | `values/themes.xml` + `values-v31/themes.xml` |
| Nextcloud | `@color/primary`（Launcher 主题） | `Theme.App.Starting`(parent=Theme.SplashScreen) + `windowSplashScreenBackground=@color/primary` + `postSplashScreenTheme=Theme.ownCloud.Launcher`（其 windowBackground 同 `@color/primary`） | `app/src/main/res/values/styles.xml` |

要点：
- **无缝衔接的核心 = 同一个 color resource**：系统 splash 的底色和窗口第一帧底色用同一资源（Signal、Nextcloud 都是）。我们 v6 已按此落地（`@color/brand_splash` 同时被系统 splash 背景和窗口背景渐变顶部引用）。
- **为什么品牌图放 windowBackground 而不是 windowSplashScreenBackground**：后者官方只收纯色；`windowSplashScreenAnimatedIcon` 又被 240/288dp 圆形蒙版裁切——"全屏品牌图"在系统层无处可放，只能走 windowBackground layer-list（或首帧自绘页）。
- **开源社区没有任何 App 把整张品牌设计图全屏铺进 windowBackground**：Retro Music 的 logo 也是"居中不拉伸"，四周露主题色。

### Q2 `windowSplashScreenBrandingImage` 的真实用法与规格

- 调研 7 个 App（Retro/Metro/VLC/Auxio/Signal/Nextcloud/Aegis）**零使用**。
- 官方规格：**200×80dp**，屏幕底部居中；内容须透明背景；官方原文 *"the design guidelines recommend against using a branding image"*（设计指南不推荐）。
- 生态中唯一典型落地者 = flutter_native_splash（`android_12.branding` → `@drawable/android12branding`，README 要求源图 800×320px，即 xxxhdpi 下的 200×80dp）。
- MusicFree 上游模板带 400×160 branding 图 = **expo 模板默认值，不是开源社区主流做法**，可考虑删除。

### Q3 `windowSplashScreenShortTimeout` 与 RN/Flutter 库源码机制

**`windowSplashScreenShortTimeout` 纠偏**：官方可配属性清单只有 6 项（Background / AnimatedIcon / AnimationDuration / IconBackgroundColor / BrandingImage / Behavior）+ 兼容库的 postSplashScreenTheme，**没有 ShortTimeout**。启动画面"自动结束"的真实语义 = ①应用画出首帧即关闭；②系统内部兜底超时（官方只说 "times out automatically"，未公开毫秒数、不可配置）。写入 styles.xml 会 AAPT 报错。

**expo-splash-screen（现代分支）** = AndroidX `core-splashscreen` 的封装：
- native 调 `installSplashScreen()`（SplashScreenManager.kt），MainActivity 注入 `SplashScreenManager.registerOnActivity(this)`
- config 插件生成 `Theme.App.SplashScreen`（parent=`Theme.SplashScreen`），写 `windowSplashScreenBackground` / `windowSplashScreenAnimatedIcon` / `postSplashScreenTheme=@style/AppTheme` / `windowSplashScreenBehavior=icon_preferred`；**不直接写 windowBackground**（AndroidX 父主题在 API<31 内部接管）、**不写 windowSplashScreenIconBackgroundColor**（要圆形底须业务自己补——本项目已补）
- 隐藏机制双保险：ReactMarker `CONTENT_APPEARED` 自动隐藏（仅当没 prevent 过）+ OnPreDraw 拦截 contentView 绘制兜底；退出 400ms alpha 淡出
- **没有超时兜底**：JS 调了 `preventAutoHideAsync()` 但 bundle 失败/崩溃时启动屏永久停留——业务须自补超时

**react-native-splash-screen（crazycodeboy）** = Dialog 遮罩 hack：`new Dialog(activity).setContentView(R.layout.launch_screen)` + `windowIsTranslucent=true` 透明窗口盖图，完全不碰 windowBackground；API 31+ 系统 splash 先弹 → Dialog 再盖 = 双段闪烁；无自动隐藏、无超时。**本项目不要混用。**

**flutter_native_splash（2.4.8）** = 不"画"启动图，只做：①PNG 按 5 个 dpi 桶切图落 `drawable-*`；②XML 模板拼 `launch_background.xml`（layer-list，底层 `<bitmap gravity="fill">` 支持整页背景图，中间 logo `gravity=center`，底部 branding 可加 padding）；③往 `LaunchTheme` 塞 `windowSplashScreen*` 属性（API31+ 走 `values-v31`）。**不生成 postSplashScreenTheme**（那是 core-splashscreen 兼容库的），由 Flutter 引擎首帧后自动切 NormalTheme。API31+ 整页背景图 `background_image` 不生效（README 明确）。

### Q4 全屏 PNG 的屏幕适配（16:9 / 20:9 / 平板不拉伸）

- 开源社区的选择：**回避整图**——纯色底 + 居中 logo（`android:gravity="center"` 不拉伸）+ vector 渐变背景。
- 整图场景的正确姿势（综合官方机制）：
  - `drawable-nodpi/`：避免系统按密度缩放；
  - `.9.png`（9-patch）：把可拉伸区放在纯色/渐变区、关键内容区设不可拉伸——真正"整图适配所有比例"的解法；
  - `sw<N>dp` 限定符（如 `drawable-sw600dp/`）：为平板单独出图；
  - scaleType：用 `centerCrop`（fill 视图裁剪）或 `gravity="center"`（原尺寸居中），**不要 `gravity="fill"` 硬拉**。
- expo 出图规格：`canvasSize = 288 * multiplier`（Android 12 图标总窗口 288dp）× mdpi~xxxhdpi 五档，logo 默认 100dp 居中，深色模式 `drawable-night-*` 全档位。

### Q5 styles.xml 完整清单：开源做法 vs RN 官方模板

| 项 | RN 官方模板（MusicFree 上游） | 开源原生 App 主流 |
|---|---|---|
| parent | `Theme.SplashScreen` | Retro/Metro：`Theme.AppCompat.DayNight.NoActionBar`；Nextcloud：`Theme.SplashScreen`；Signal：正式主题上覆盖 |
| windowSplashScreenBackground | 纯色 `#27282C` | 纯色，且**与正式主题 windowBackground 同色资源** |
| windowSplashScreenAnimatedIcon | 576×576 PNG | **vector drawable**（Signal `ic_splash`、Nextcloud 复用 `ic_launcher_foreground`） |
| windowSplashScreenBrandingImage | 400×160 PNG | **无人使用** |
| windowBackground | 不定制 | Retro/Metro：layer-list(纯色+居中 logo)；Signal/Nextcloud：与 splash 同色纯色 |
| postSplashScreenTheme | 不设（靠 JS 侧 hide） | Nextcloud：设 Launcher 主题 |
| 全屏品牌图 | 无 | 无（所有调研 App 都没做） |

| 层 | 当前实现 | 与调研结论的对应 |
|---|---|---|
| 系统 splash（API31+，values-v31） | 纯色 `#F8F9FA`（=渐变顶部，`@color/brand_splash` 同源）+ 圆形品牌蓝底 `#4055D4` + 白音符 | 官方槽位上限：纯色 + 居中圆图标 ✓；同源做法 = Signal/Nextcloud ✓ |

## 4. 结论清单：要补什么（✓ 已做 / △ 建议 / ✗ 不要做）

1. ✓ **windowBackground layer-list 全图（v6）**：PageBackground 同款渐变背景 + 渐变圆角容器 + 白音符 + 品牌名，品牌图与软件内一致。
2. ✓ **系统 splash 纯色与窗口背景同源**（`@color/brand_splash` 同一资源）——Signal / Nextcloud 的核心做法，三段零跳变。
3. ✓ **渐变只放 windowBackground**（系统 splash 层官方仅纯色，依据见分报告 03 §2.4）。
4. △ **expo-splash-screen 无超时兜底**（两个库都没做、必须自己补的坑）：建议在 `src/entry/bootstrap/bootstrap.ts` 的 `preventAutoHideAsync()` 后加 3~5s 超时 `hideAsync()`，防止 bundle 加载失败时启动屏永久停留。
5. △ **深色模式 night 变体**：windowBackground 现无 `values-night` / `drawable-night` 变体（系统 splash 深色下仍浅色 = 既有决策）；如要深色跟随，需补整套 night 资源。
6. △ **AnimatedIcon 可换 vector**（Signal 做法，免 PNG 被 mask 裁切的边缘风险，免多档切图）——可选优化。
7. △ **`android:statusBarColor="@android:color/transparent"`**（Retro Music 做法，启动期状态栏不突兀）——可选。
8. ✗ **不要用 `windowSplashScreenShortTimeout`**（官方不存在，AAPT 报错）；**BrandingImage 不启用**（官方不推荐、开源零使用）；上游模板的 branding 图可考虑删除。
9. ✓ **未混用 Dialog 遮罩方案**（crazycodeboy 坑）、**未加 `windowIsTranslucent`**（那是 Dialog 方案才需要的，加了对系统 splash 反而有害）。
10. ✓ **出图规格**：既有音符素材 1298×1298 透明底白音符（音符≈100% 画布，容器内 78%），符合 288dp 画布思路，未被 mask 裁切。

## 2. 各项目核心机制（回答"为何无缝用自制图、看不出系统纯色"）

### Retro Music ——「纯色底 + 居中 Logo」双轨

- **旧设备（API<31）**：`values/styles.xml:123` `windowBackground=@drawable/splash`，`drawable/splash.xml` 两层 layer-list：`?attr/colorPrimary` 纯色满屏 + `<bitmap gravity="center" src="@drawable/ic_splash">`（512×512 PNG，仅 `drawable-xxxhdpi/` 一档）。第一帧即品牌色满屏，无系统白底帧。
- **新设备（API≥31）**：`values-v31/styles.xml:21-24` `Theme.RetroMusic.SplashScreen` parent=`Theme.SplashScreen`（androidx `core-splashscreen:1.0.1`），**只设** `windowSplashScreenAnimatedIcon=@drawable/avd_splash`（411dp animated-vector 品牌动画）+ `AnimationDuration=1000`；`windowSplashScreenBackground` / `IconBackgroundColor` / `BrandingImage` / `postSplashScreenTheme` 全部未设；全仓无 `installSplashScreen()` 调用。
- **无缝关键**：① 系统 Splash 背景继承 `Theme.SplashScreen` 默认（`colorBackground` 系），而 `AbsThemeActivity.onCreate()` 在 `super.onCreate()` 前 `setTheme(getThemeResValue())` 切到正式主题（其 `windowBackground=?colorSurface`，`styles_parents.xml` 全部主题统一）——两段都在 Material3 表面色系，肉眼无跳变；② 图标是自制品牌动画矢量，非系统 launcher 图标；③ `statusBarColor=transparent`。
- **评级**：非全图自制（icon 仅 512×512 居中、无全屏整图、无 branding）。

### Auxio ——「系统 Splash + 自制动画图标」

- 无任何 `windowBackground` 定制、无 layer-list/bitmap/gradient 自制 drawable、无独立 SplashActivity（Manifest 零 splash 命中）。
- `values-v31/styles_core.xml:5-6` `Theme.Auxio.V31` 只设 `windowSplashScreenAnimatedIcon=@drawable/ic_splash_anim`（432dp animated-vector，A 字四笔描边 850ms 动画）+ `AnimationDuration=1000`；父主题 `Theme.Material3Expressive.DynamicColors.DayNight`。
- **无缝关键（隐式）**：背景 100% 由系统/Material3 DynamicColors 派生（`colorBackground`），与 App 第一帧（Material3 默认 `colorSurface`）同色板，无显式对齐；V29 起状态栏透明。
- **评级**：背景纯系统/Material3 动态色 + 自绘图标动画，介于"纯系统默认"与"纯色+logo"之间；无缝完全靠动态取色隐式统一。

### Metro —— Retro Music 同源 fork，双轨同构

- 旧设备：`values/styles.xml:122-125` 同名 `Theme.RetroMusic.SplashScreen` + `drawable/splash.xml`（`?attr/colorPrimary` 满铺 + 居中 512×512 `ic_splash.png`），逐字同 Retro。
- 新设备：`values-v31/styles.xml:21-24` parent=`Theme.SplashScreen`（`core-splashscreen:1.0.0`），仅 `windowSplashScreenAnimatedIcon=@drawable/avd_splash`（411dp 动画矢量）+ 1000ms；背景/BrandingImage/postSplashScreenTheme 未设；`AbsThemeActivity.kt:52` 提前 `setTheme`。
- **评级**：双轨（layer-list 兜底 + 系统 Splash 动画图标）；无缝靠"主题色窗口背景 + 品牌图标动画遮挡"，严格说 12+ 上底色跳变仍存在但被动画遮挡。

### Phonograph ——「纯系统默认」（最裸，反面样本）

- 零自制：无 splash.xml / ic_splash / Splash 主题；Manifest 启动 Activity 直接复用 `Theme.Phonograph.Light`；全 res 唯一 `windowBackground` 是纯黑主题的 `@android:color/black`（`styles_parents.xml:62-68`）；无 values-v31、无 core-splashscreen。
- 冷启动 = AppCompat 浅色默认白底 + `values-v21` 透明状态栏 + `AbsThemeActivity.java:26` 提前 `setTheme(用户主题)`（纯黑用户经历白→黑跳变）。
- **评级**：连"纯色+logo"都算不上——证明"无缝"是显式工程，不是默认值。

## 4. 用户核心问题归纳：开源 App"无缝自制图、看不出系统纯色"的四类机制

1. **第一帧就是自制画面（API<31 旧轨）**：`windowBackground`=layer-list（纯色满屏 + 居中 logo），窗口创建即品牌画面，系统根本没有"白底"帧可露——Retro/Metro 旧轨与国产软件反编译（网易云/QQ 车机）同款范式。
2. **同色系/同源色（API≥31 新轨）**：系统 Splash 背景不设（Retro/Auxio 赌 Material3 surface 系）或显式同源（Signal/Nextcloud 用同一 color resource），落地第一帧 `?colorSurface` → 两段同色系无跳变。
3. **品牌图标替换系统图标**：`windowSplashScreenAnimatedIcon` = 自制（动画）矢量/PNG，系统拿到的不是默认 launcher 图标——图标层也不露馅（Retro/Metro `avd_splash` 411dp、Auxio `ic_splash_anim` 432dp）。
4. **主题切换提前**：`onCreate` 在 `super.onCreate()` 前 `setTheme(真主题)`，启动主题停留压到最短。
5. 反面：Phonograph 什么都不做 → 白底/跳变可见。

## 5. 对极悦界（v6）的更新结论

- 当前 v6 = 机制 1+2+3 全占：`windowBackground` layer-list（渐变 + 渐变圆角容器 + 白音符 + 品牌名）、系统 splash 纯色 `#F8F9FA` 与渐变顶部**同一 color 资源**（`@color/brand_splash`，Signal/Nextcloud 级显式同源，4 个开源项目没有一个做到）、自绘白音符图标。横向对比属最完整组合。
- 4 个开源音乐 App 没有一家做"全屏整图启动"——它们靠"纯色/同色系 + 居中 logo + 品牌图标动画"营造无缝；极悦界 v6 的 layer-list 品牌画面已超过它们绝大多数，与国产软件反编译范式同一档。
- 可借鉴补强（建议项，未改代码）：① `windowSplashScreenAnimatedIcon` 未来可换 vector/animated-vector（Retro 411dp `avd_splash` 做法），免 PNG 密度档；② Retro/Metro 的"提前 setTheme"角色在极悦界由 expo-splash-screen 承担（JS 就绪后 hide，等价）；③ BrandingImage 确认 4 项目零使用，上游模板 400×160 可删；④ `windowSplashScreenShortTimeout` 确认不存在、零使用。
