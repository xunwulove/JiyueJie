# 启动页白屏问题与实现路径（反编译实测版）

> 状态：已修复（2026-10-12）
> 关联：极悦界（MusicFree RN 0.76.5 fork）Android 冷启动体验
> 本文档替代早期《极悦界-Android启动页技术调研报告》中"方案 C 推断部分"——该报告关于"大厂=系统 splash 纯色+圆形图标"的结论为**机制推断**，经反编译两大厂 APK 实锤后**修正**，详见下文第 3 节。

---

## 1. 问题背景

用户设备（华为平板 / 手机）冷启动「极悦界」时：
1. 点开约 **1 秒白屏**（系统 splash 阶段）；
2. 行楷"极悦界"文字**延迟出现/不出现**；
3. 桌面图标被裁切 / 嵌套显示；
4. 用户对照：QQ音乐 / 网易云"一点开就是品牌图+图标+文字"，无白屏。

## 2. 根因（旧实现）

旧原生配置（`android/app/src/main/res/values/styles.xml`）：

```xml
<style name="Theme.App.SplashScreen" parent="Theme.SplashScreen">
    <item name="windowSplashScreenBackground">@drawable/splashscreen_background</item>  <!-- ❌ layer-list drawable -->
    <item name="windowSplashScreenAnimatedIcon">@drawable/splashscreen_icon</item>       <!-- ❌ 1536×1536 超规格 -->
    <item name="postSplashScreenTheme">@style/AppTheme</item>
    <item name="android:windowBackground">@drawable/splashscreen_background</item>
</style>
```

- `windowSplashScreenBackground` 传 **layer-list drawable**：违反 Android 12+ 官方契约（背景必须为**单一不透明色**）。华为等兼容层只处理纯色路径 → 白屏 / 近白屏；
- `splashscreen_icon.png` 为 **1536×1536**：官方 xxxhdpi 画布上限 1152×1152、可见圆 768px → 解码延迟 / 裁切异常；
- 行楷文字图放在 layer-list 背景层，白屏期间不可见。

## 3. 反编译实测（决定性证据）

用户提供两个 APK，用 aapt2 反编译资源层（Manifest / themes / drawable / colors），结论如下：

### 3.1 网易云音乐（6.2.81，com.netease.cloudmusic.iot）

| 项 | 实测值 | 证据 |
|---|---|---|
| Launcher | 独立 `LoadingActivity`（非主界面） | Manifest MAIN/LAUNCHER |
| 启动画面载体 | 主题 `windowBackground` = layer-list | 主题 0x7f120011 → drawable/ii.xml |
| layer-list 内容 | 近白底 `#F9F9F9` + 红色氛围渐变（`#33FF3A3A→#00FF3A3A` 自下而上渐隐）+ 居中透明底品牌图（692×546 红白 logo） | drawable/ii.xml、color/tr、fp.xml、aet.png |
| 系统 splash 属性 | **零配置**（windowSplashScreenBackground / AnimatedIcon 全资源表 0x0101053x 零命中） | aapt2 dump resources |

### 3.2 QQ音乐车机版（3.16.0.2，com.tencent.qqmusiccar）

| 项 | 实测值 | 证据 |
|---|---|---|
| Launcher | 独立 `AppStarterActivity` | Manifest |
| 启动画面载体 | 主题 `QQMusicForAppStartThemeFirst` 的 `windowBackground` = layer-list | 主题 0x7f110142 → spalshstatic |
| layer-list 内容 | 纯白底 `#FFFFFF`（night `#FF292D3B`）+ 居中 `splash_logo`（1399×693 绿色光晕 QQ 音符，距底 100dp）+ 底部 `splash_logo_bottom`（796×157 "QQMUSIC / Powered by 天琴实验室 银河音效 臻品全景声"，距底 28dp） | spalshstatic、splash_background、splash_logo、splash_logo_bottom |
| 系统 splash 属性 | **零配置** | aapt2 dump resources |
| 额外 | 开屏广告转场 `change_splash_ad_transform` | 主题 item |

### 3.3 结论：大厂标准做法（与调研报告推断不符）

> **大厂根本不配置 Android 12+ 系统 splash 属性**（不走"纯色+圆形图标"路径）。

- **系统 splash**：保持默认（背景取 `windowBackground` 颜色 ≈ 白/近白，与品牌画面同色）→ 极短、几乎不可感知；
- **品牌画面**：全部由启动 Activity 主题的 **`windowBackground` = layer-list（纯色底 + 品牌整图 + 文字）** 承载——窗口一创建，windowBackground **先于一切布局立即全屏绘制**；
- 品牌图放 windowBackground 是**全屏窗口背景**，**非圆、不被圆形遮罩裁切**，这正是用户看到的"一点开就是品牌图+图标+文字"；
- 行楷/品牌文字在 windowBackground 的品牌整图内或启动 Activity 布局内。

### 3.4 对旧实现的关键修正

- 我们之前把品牌整图放进了 **`windowSplashScreenBackground`**（系统 splash 属性）→ 违规 → 华为白屏；❌
- 正确位置是 **`windowBackground`**（Activity 窗口背景，合法、立即显示、非圆不裁切）；✅
- 系统 splash 只放**纯色**（合法契约），图标位**透明隐形**（避免圆形遮罩裁切 / 两段感）。

## 4. 新实现路径（已落地）

### 4.1 修改文件清单

| 文件 | 变更 |
|---|---|
| `res/values/colors.xml` | 新增 `brand_splash` = `#F1F4FA`（品牌渐变 `#EAF0FA→#F8F9FA` 视觉中间色） |
| `res/drawable/splashscreen_brand_window.xml`（新建） | windowBackground = layer-list：全屏渐变（#EAF0FA→#F8F9FA）+ `splashscreen_brand` 整图（1024×1330，图标+行楷"极悦界"）`gravity=center + scaleType=fitCenter` 等比缩放居中 |
| `res/values/styles.xml` | `AppTheme.windowBackground = @drawable/splashscreen_brand_window`（品牌画面立即显示）；`Theme.App.SplashScreen` 仅留 API<31 兜底（windowBackground 整图 + postSplashScreenTheme） |
| `res/values-v31/styles.xml`（新建） | Android 12+ 系统 splash：`windowSplashScreenBackground = @color/brand_splash`（纯色，官方契约）；`windowSplashScreenAnimatedIcon = @android:color/transparent`（隐形）；`postSplashScreenTheme = AppTheme` |
| `src/entry/bootstrap/BrandSplash.tsx` | 整图由"短边×0.5 定宽"改为 **contain 全图适配**（flex:1 + alignSelf:stretch），与原生 windowBackground 的 fitCenter 同效果 → 切换无大小跳变；保留 spring 0.92→1 + MIN_DISPLAY_MS=1500 淡出 |

### 4.2 启动时序（修复后）

```
点击图标
  → 系统 splash（API31+）：纯色 #F1F4FA（合法、不白屏、无圆形图标）   [几十~几百 ms]
  → 窗口创建：windowBackground 立即全屏绘制 品牌渐变 + 图标 + 行楷"极悦界"整图（非圆、完整）
  → RN 首帧：BrandSplash 同一整图 + 同一渐变无缝接管（bootstrap 完成后 ≥1500ms 再淡出）
  → 主界面
```

API<31：无系统 splash，窗口直接显示 windowBackground 品牌整图（与旧行为一致，非白屏）。

### 4.3 为什么这样是对的

- `windowSplashScreenBackground` 遵守官方"单一纯色"契约 → 华为/各 ROM 不再走异常路径 → **不白屏**；
- 品牌整图放 `windowBackground` → **立即显示、非圆、不被圆形遮罩裁切、含行楷文字**（对齐网易云/QQ 实测）；
- 系统 splash 图标隐形 → 无"圆形 logo → 整图"的两段突兀感；
- 两层（原生窗口背景 / RN BrandSplash）同一张图、同一渐变、同一显示方式（fitCenter ≈ contain）→ **切换零跳变**。

## 5. 验证要点（装机）

1. 冷启动（杀进程后点图标）：无白屏，直接见品牌渐变 → 图标+行楷"极悦界"完整出现；
2. 系统 splash 阶段无圆形 logo（隐形）、无两段感；
3. 平板 / 手机 / 横竖屏均正常（fitCenter 自适应）；
4. 深色模式：系统 splash 仍为品牌浅色（与 BrandSplash 一致，保持现状行为）；
5. 桌面图标不受影响（mipmap ic_launcher 独立）。

## 6. 遗留说明

- `splashscreen_background.xml`（旧 layer-list：渐变+文字位图）与 `splashscreen_icon.png`（1536×1536）**不再被任何主题引用**，可保留作历史资源或后续清理（未删除，避免影响其他引用——已核查无引用）；
- 调研报告中"图标规格 1152/768、颜色衔接、慢动作录屏验证"等通用结论仍有效；"大厂=纯色+圆形图标"部分已被本文档 3.3 修正。
